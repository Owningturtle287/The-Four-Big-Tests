About the model +
This is a transparent model, not a diagnosis. The horizontal axis runs from public coordination to market coordination. The vertical axis runs from civic autonomy to institutional authority. Items have documented coefficient magnitudes and some cross-load across axes. The instrument has not been normed on a representative population, so it should not be used to assign party identity, predict a vote, or make high-stakes decisions.
